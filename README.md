Study Flow – Chrome Extension

Study Flow is a productivity-focused Chrome extension designed to help students manage their study time efficiently and maintain focus during study sessions. The extension provides a simple and distraction-free interface to support consistent and effective studying.

Features

Focus-based study timer
Minimal and distraction-free user interface
Easy-to-use controls
Lightweight and fast Chrome extension

Installation (Developer Mode)

Clone or download this repository
Open Google Chrome
Navigate to chrome://extensions/
Enable Developer mode
Click Load unpacked
Select the project folder
The extension will be added to your browser
Usage

Click on the Study Flow extension icon in the Chrome toolbar
Start the study timer
Focus on your tasks until the timer completes
Repeat sessions to build a productive routine
